# FlowerPower-UI Project Overview

FlowerPower-UI is a web-based interface for the FlowerPower Python library, designed to provide users with an intuitive way to interact with data workflow frameworks through a modern web application.

## Technical Stack
The application leverages a carefully selected technology stack optimized for Python-centric development:

- **Backend Framework**: Sanic - A fast, async Python web framework that provides excellent performance for handling web requests
- **Frontend Styling**: DaisyUI with Tailwind CSS - Offers a comprehensive component library built on Tailwind's utility-first approach for rapid UI development
- **HTML Templating**: htpy - A Python-based HTML templating solution that keeps template logic within the Python ecosystem
- **Reactive Frontend**: Datastar via datastar-py - Enables dynamic, reactive user interfaces without requiring separate JavaScript frameworks

## Project Goals
FlowerPower-UI serves as a bridge between the powerful data workflow capabilities of the FlowerPower library and end users who need a visual, interactive interface to design, monitor, and manage their data processing pipelines. The application maintains Python-first development principles while delivering a responsive, modern web experience.
This architecture choice allows developers to build the entire application stack in Python while still providing users with a rich, interactive frontend experience typically associated with JavaScript-heavy applications.
